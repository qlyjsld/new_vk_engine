# new_vk_engine

## Features
* Compute Shader Rendering
* Mesh Shader Rendering
* Texture Generating
* glTF Loading
* Volumetric Rendering
* ImGui Integration

## Getting Started
This project uses CMake and Make, to clone and build:

```
1. git clone --recursive https://github.com/qlyjsld/new_vk_engine
2. cd new_vk_engine
3. mkdir build && cd build
4. cmake ..
5. make -j <threads>
6. ./src/vk_engine

```
